# TrendPlay 新游戏添加指南

## 添加新游戏卡片到主页

复制以下模板到 `index.html` 的 `<div class="games-grid">` 中：

```html
<!-- Game X: [游戏名称] -->
<a href="[游戏目录]/" class="game-card">
    <div class="game-icon">🎮</div>
    <h2 class="game-title">[游戏名称]</h2>
    <p class="game-desc">[游戏简短描述 - 1-2句话]</p>
    <span class="game-tag">🔥 New</span>
</a>
```

### 游戏图标 Emoji 参考
- 🎮 - 通用游戏
- 🔗 - 单词链类
- 🎵 - 音乐/节奏类
- 🧩 - 拼图/益智类
- ⚡ - 快速反应类
- 🎯 - 射击/精准类
- 🏃 - 动作/跑酷类
- 🧠 - 脑力/策略类

### 游戏标签参考
- 🔥 Popular - 热门游戏
- 🔥 Trending - 正在流行
- 🚀 Soon - 即将上线
- ✨ New - 最新上线
- 🏆 Featured - 推荐游戏

## 创建新游戏页面

1. 在 `D:/Trendplay/wordbeat-game/` 下创建新目录 `[游戏名-kebab-case]/`
2. 复制 `template.html` 到新目录的 `index.html`
3. 替换所有 `[游戏名称]`、`[游戏描述]` 等占位符
4. 添加游戏逻辑（JavaScript）
5. 添加 SEO 内容区块（参考其他游戏页面）
6. 提交并部署

## 更新主页 SEO 内容

修改 `<div class="seo-content">` 中的游戏列表，确保包含新游戏。
